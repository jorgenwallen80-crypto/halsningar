# Uppdatera till v6.5

1. Ersätt filerna i GitHub med innehållet i denna version och gör en commit.
2. Kör `supabase/uppdatera-handelser-v6_5.sql` en gång i Supabase SQL Editor.
3. Vänta på Netlify-publiceringen eller välj Trigger deploy.
4. Ladda om appen helt eller starta om den installerade PWA:n.
5. Öppna admin och fyll i namn samt välkomsttext under Personlig välkomsthälsning.

Uppdateringen ändrar inte befintliga koder, händelser, bilder eller quizdata.
